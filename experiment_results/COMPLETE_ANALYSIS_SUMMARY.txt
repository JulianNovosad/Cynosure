CAN IT BECOME SMART?
================================================================================

YES, but requires:

1. REWARD RESTRUCTURING
   Current: Pure distance penalty → Always negative reward
   Needed: Shaped reward with baseline

   Example:
     initial_distance = 10.39
     progress = (initial_distance - current) / initial_distance
     reward = 10.0 * progress  # Always positive for any progress

2. CURRICULUM LEARNING
   Current: Target at fixed far distance
   Needed: Gradually increase difficulty

   Example:
     Episodes 1-5: Target 3 units away (easy)
     Episodes 6-10: Target 5 units away (medium)
     Episodes 11-20: Target 8.6 units away (hard)

3. OR PLASTICITY REDESIGN
   Current: Only learns on reward > 0.1
   Needed: Penalty-based plasticity

   Add inverse rule:
     if reward < -50: weaken_synapses(reward)

With these fixes, both 4.2M and 1M should learn.
Learning speed difference (if any) would then appear.
